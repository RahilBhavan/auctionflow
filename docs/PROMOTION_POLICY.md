# Promotion Policy

Nothing in Milestone 0 is promoted or live. A strategy/default remains `RESEARCH_ONLY` and alert-only unless a later approved milestone documents evidence, review, and rollback criteria.

Promotion requires, at minimum:
1. dated verification of every applicable official Topstep rule from official documentation;
2. deterministic unit/property/golden tests mapped to each enforced rule;
3. replay evidence across representative and adversarial fixtures, including malformed data and state gaps;
4. independent risk and leakage review;
5. explicit configuration hash, owner, effective date, and rollback version;
6. separate approval for any future gateway or order capability.

No promotion may silently add ProjectX connectivity, credentials, live data, order submission, scale-in, re-entry, reversal, or stop widening. Any future production token must be consumed only after official API entry acceptance, unlike this milestone's simulated journal-time consumption.
